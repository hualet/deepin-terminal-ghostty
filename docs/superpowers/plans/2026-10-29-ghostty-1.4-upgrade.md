# Ghostty 1.4 Engine Upgrade Implementation Plan

> Execute this stage with superpowers:subagent-driven-development, using one
> implementer followed by spec and quality review. Do not commit implementation.

**Goal:** Replace the current bundled VT engine with the pinned 1.4 source build
while preserving existing terminal behavior.

**Architecture:** Treat lib/libghostty-vt.so and lib/include as one artifact set.
Qt remains the renderer and application composition stays in src/app.

**Tech Stack:** C++20, Qt6, DTK6, CMake, Qt Test, Zig 0.17.0.

## Execution evidence

- Baseline app/tests built. All 12 baseline CTest entries passed across the
  prompt environments documented in `docs/dependencies/ghostty-vt.md`.
- New regressions failed against the old artifact for its old version and bare
  CR safety result, then passed against the pinned build.
- Official Zig 0.17.0 SHA256 verified; exact build and artifact metadata are in
  the dependency document. Default Zig remains 0.16.0.
- All 35 installed headers and the shared library were replaced together. No
  production Qt source migration was required.
- OSC 7501 support-query test migrated from a fixed nine-byte response to the
  complete BEL-terminated capability reply documented by upstream 1.4.
- Focused integration: 27 cases passed. Complete TerminalWidget: 196 passed.
  Other 11 CTest entries: all passed. One existing D-Bus-dependent MainWindow
  case was skipped because no session bus was available.
- Changed C++ formatting and `git diff --check` passed. Changes remain
  uncommitted for spec and quality review.
