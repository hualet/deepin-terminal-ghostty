# Internationalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Qt-based translation support with English source strings and initial `zh_CN` and `es` translations.

**Architecture:** Keep source text in code as English, add Qt Linguist build/release support in CMake, and load matching app translations during startup from a standard translations directory near the executable. Limit scope to existing `tr()` UI strings and avoid adding a runtime language selector.

**Tech Stack:** C++20, Qt6 Widgets, Qt6 LinguistTools, CMake, DTK6

---

**Files:**
- Modify: `tests/test_appsettings.cpp`
- Test: `build/tests/test_appsettings`

- [ ] **Step 1: Write the failing test**

Add a focused test that proves shortcuts in different settings groups are readable:

```cpp
    void testShortcutsAcrossGroups() {
        auto *s = AppSettings::instance();
        QCOMPARE(s->shortcut("copy"), QKeySequence(QStringLiteral("Ctrl+Shift+C")));
        QCOMPARE(s->shortcut("select_left_workspace"), QKeySequence(QStringLiteral("Alt+Left")));
        QCOMPARE(s->shortcut("switch_fullscreen"), QKeySequence(QStringLiteral("F11")));
```

Run: `QT_QPA_PLATFORM=offscreen ./build/tests/test_appsettings testShortcutsAcrossGroups`

### Task 2: Add Build-Time Translation Pipeline

**Files:**
- Modify: `CMakeLists.txt`
- Create: `translations/deepin-terminal-ghostty_zh_CN.ts`
- Create: `translations/deepin-terminal-ghostty_es.ts`

- [ ] **Step 1: Add translation inputs and release targets**

Update `CMakeLists.txt` to:

- require `Qt6` `LinguistTools`
- declare app source files used for extraction
- define the `zh_CN` and `es` `.ts` files
- generate `.qm` files with `qt_add_lrelease(...)`
- make the app target depend on the translation release target
- install generated `.qm` files under `share/deepin-terminal-ghostty/translations`

- [ ] **Step 2: Populate initial translation sources**

Create checked-in `.ts` files with translated entries for the current `tr()` UI strings from:

Use English source text, Simplified Chinese translations, and Spanish translations. Leave untranslated JSON-only strings out of scope.

- [ ] **Step 3: Run build to verify release output exists**

Run: `cmake -B build -DBUILD_TESTING=ON && cmake --build build`

Expected: successful build and generated `.qm` files in the build tree.
