核心特性

快、稳、现代——每一处细节

从 VT 引擎到渲染管线，从交互细节到桌面集成，为下一代终端体验而打造。

Ghostty VT 引擎

采用 Ghostty 的高性能 VT 解析与状态管理，渲染流畅，兼容性出色，支持 24-bit 色彩与 Kitty 键盘协议。

AI 进程智能识别

自动检测 Claude、Codex、Gemini、Copilot、Opencode、Qwen 等 AI 工具，标签栏实时显示对应图标。

命令状态追踪

每条命令的运行、成功、失败状态以彩色圆点呈现在标签上，无需切回即可掌握全局。

垂直标签 + 分屏

侧边垂直标签栏充分利用屏幕宽度；标签内可水平、垂直分屏，灵活编排你的工作区。

会话保存与恢复

重启后自动还原标签、分屏布局、工作目录，甚至终端内容与颜色，工作状态不丢失。

主题 / 透明 / 模糊

内置明暗及跟随系统主题，支持自定义配色；背景透明度与毛玻璃模糊随心调节。

Kitty 图片协议

支持 Kitty 图片协议，可在终端内直接展示图片，支持多层 z 轴渲染与直接内联存储。

原生 DTK 深度集成

基于 DTK6 构建，深度融入 deepin 桌面体验——窗口管理、标题栏、设置面板均为原生风格。

远程与自动化

内置远程服务器管理；配合 dtermctl 命令行工具，可程序化创建窗口、分屏、发送指令。

使用方式

三分钟，开始使用

支持 Debian 包安装、源码编译和玲珑打包，总有一种适合你。

Debian / deepin

下载 .deb 安装包

# 安装依赖 $ sudo apt install cmake qt6-base-dev \ build-essential binutils \ libdtk6widget-dev libdtk6core-dev \ libdtk6gui-dev # 安装 deb 包 $ sudo dpkg -i deepin-terminal-ghostty_*.deb
源码编译

从源码构建

# 克隆仓库 $ git clone <repo-url> $ cd deepin-terminal-ghostty # 构建并运行 $ cmake -B build $ cmake --build build $ ./build/deepin-terminal-ghostty
玲珑包

使用 ll-builder

# 构建玲珑包 $ cd linglong $ ll-builder build # 导出安装包 $ ll-builder export

快捷键速查

新建标签页Ctrl + T
关闭标签页Ctrl + W
垂直分屏Ctrl + D
水平分屏Ctrl + Shift + D
查找Ctrl + F
复制Ctrl + C
粘贴Ctrl + V
切换标签页Alt + 1-9
dtermctl 自动化

用命令行控制终端

dtermctl 让你程序化地创建窗口、打开标签、分屏，甚至向指定面板发送命令——非常适合自动化和 AI 工作流编排。

# 新建窗口并运行命令 $ dtermctl new-window -- npm run dev # 在当前窗口分屏 $ dtermctl split-pane --direction vertical # 列出所有面板 $ dtermctl list-panes
